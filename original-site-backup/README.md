# Original ciu1958.org — archive

Snapshot of the previous ciu1958.org website (a React single-page app), captured
2026-07-06 before the redesign replaced it.

Contents:

- `index.html` — the page as served (React SPA shell + inlined content)
- `assets/index-*.js`, `assets/index-*.css` — the app bundles
- `assets/img/hero-banner.jpg` — hero image
- `favicon.ico`, `favicon-192.png`, `apple-touch-icon.png`
- `cdn/` — images the app loaded from its CDN (d2xsxph8kpxj0f.cloudfront.net):
  the workers illustration, contact background, and official CIU logo. They are
  saved here for preservation; the bundle still references the CDN URLs, so this
  archive may not render fully offline — it is a content backup, not a mirror.
